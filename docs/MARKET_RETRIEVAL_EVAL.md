# market_docs 검색 평가

설계서 B-3의 검증 방법으로 `market_docs` 검색 성능을 측정했습니다. 작성일 2026-09-30.

## 방법

- 평가 세트: 전체 142개 청크 중 200자 이상 청크에서 한국어 20개, 영어 10개를 무작위 추출(seed 42)하고, LLM이 청크마다 50자 이내 한국어 질문을 생성했습니다. `data/market/eval/questions.json`
- 지표: 질문마다 정답 청크 1개 기준 Recall@5, MRR@5. 그룹은 ① 한국어 질문 → 한국어 청크(ko), ② 한국어 질문 → 영어 청크(en), ③ 전체(all)
- 모델마다 메모리 내 Chroma에 같은 청크를 적재하고, 운영 코드의 `mmr_search`, `hybrid_search`를 그대로 호출했습니다.

```bash
PYTHONPATH=src python -m ai_investment.retrieval_eval questions market
PYTHONPATH=src python -m ai_investment.retrieval_eval score market --models kure bge-m3 e5
PYTHONPATH=src python -m ai_investment.retrieval_eval qualitative market
```

| 변형 | ko R@5 | en R@5 | all R@5 | all MRR |
|---|---:|---:|---:|---:|

| BM25 + **similarity** 0.4/0.6 | 0.850 | 0.800 | 0.833 | 0.664 |
| BM25 + similarity 0.2/0.8 | 0.850 | 0.800 | 0.833 | 0.664 |
| BM25 + MMR 0.2/0.8 | 0.600 | 0.700 | 0.633 | 0.531 |

## 해석

1. **MMR이 성능을 떨어뜨립니다.** `lambda_mult=0.5`의 다양성 가중이 정답 청크를 상위 5개 밖으로 밀어냅니다. Dense 부분을 similarity로 바꾸면 hybrid가 dense 단독과 같은 0.833으로 회복되고, BM25 가중치(0.4 vs 0.2)는 결과를 바꾸지 않습니다.
2. **BM25는 한국어 질문 → 영어 문서에서 거의 작동하지 않습니다**(R@5 0.2). 공백 기준 토큰화라 언어가 다르면 겹치는 토큰이 없습니다. IFR 자료가 영어라 시장 수치 검색에서 약점이 됩니다.
3. **임베딩 모델**: 설계서 판정 기준(① ko 그룹 Recall@5)에서 bge-m3 0.90 > KURE-v1 0.85 = e5 0.85입니다. 다만 0.05 차이는 20문항 중 1문항이라 통계적으로 의미 있는 차이로 보기 어렵고, 전체 MRR은 KURE-v1이 더 높습니다. e5는 영어 청크에서 크게 떨어집니다.

## 정성 평가

설계서 방식대로 도메인 질문 5개의 운영 검색(`search_market_docs`) 상위 5개를 확인했습니다. 아래는 변경 전(BM25 + MMR) 결과이며, 변경 후 결과는 '적용 결과' 절에 있습니다.

| 질문 | 정답이 있는 청크 | 상위 5개 포함 |
|---|---|---|
| 휴머노이드 시장 성장률은? | SPRi p.14 Citi 전망표(CAGR 60.7%) | X (관련 p.16·17은 포함) |
| 2024년 전 세계 산업용 로봇 설치 대수는? | IFR p.8 | O (1위) |
| 한국의 제조업 로봇 밀도는? | 스타트업맵 p.7 맺으며(1,012대) | X |
| 국내 물류 자율주행 로봇 스타트업은? | 스타트업맵 p.8 물류·유통 줄 | 부분 (p.6 본문, 인접 청크) |
| 서비스 로봇 중 가장 많이 설치된 용도는? | IFR p.29(운송·물류 52%) | X (p.30 성장률만) |

## 한계

- 정답 청크를 하나로 두어서, 여러 청크가 답할 수 있는 일반적인 질문("피지컬 AI의 정의는?")은 Recall이 낮게 나옵니다. MMR처럼 결과를 다양화하는 방식이 이 기준에서 더 불리합니다.
- 문항 수가 30개라 모델 간 0.05 수준의 차이는 순위를 확정할 근거가 되지 않습니다.
- 질문을 LLM이 청크를 보고 만들었기 때문에, 실제 사용자 질문보다 청크 표현과 가까울 수 있습니다.

## 적용 결과

2026-09-30에 `hybrid_search`의 Dense를 similarity로 바꿨습니다(`tools/rag.py`, `docs/TOOL_SELECTION.md` 반영). 운영 코드로 다시 측정한 결과입니다.

| Retriever | ko R@5 | ko MRR | en R@5 | en MRR | all R@5 | all MRR |
|---|---:|---:|---:|---:|---:|---:|
| KURE-v1 hybrid (변경 전: BM25 + MMR) | 0.600 | 0.512 | 0.700 | 0.517 | 0.633 | 0.514 |
| **KURE-v1 hybrid (변경 후: BM25 + similarity)** | **0.850** | **0.683** | **0.800** | **0.625** | **0.833** | **0.664** |

정성 평가 5문항은 확실히 찾은 문항이 1개에서 3개로 늘었습니다.

| 질문 | 변경 전 | 변경 후 |
|---|---|---|
| 휴머노이드 시장 성장률은? | X | X (SPRi p.16~18 관련 청크만) |
| 2024년 전 세계 산업용 로봇 설치 대수는? | O (1위) | O (1위) |
| 한국의 제조업 로봇 밀도는? | X | X |
| 국내 물류 자율주행 로봇 스타트업은? | 부분 | O (2위, 물류·유통 자율주행 줄) |
| 서비스 로봇 중 가장 많이 설치된 용도는? | X | O (3위, IFR p.29) |

남은 두 문항은 정답이 표(SPRi p.14)나 결론 문단(스타트업맵 p.7) 안에 있어, 청크 앞부분의 다른 주제에 묻히는 경우입니다.
