# 실습용 기업 검색 목록과 선정 기준

확인일: 2026-10-13. 목록은 공개 자료가 있는 기업을 먼저 검색하기 위한 출발점이다.
투자 추천이나 현재 선정 조건 통과를 의미하지 않는다. 실행할 때 최신 투자 단계,
상장·인수 여부, 기술 자료와 실제 적용 근거를 다시 확인한다.

공식 사이트와 외부 자료가 확인된다는 점을 기준으로 구성했다. Tavily가 반환하는
검색 결과만으로 필요한 사실을 확보하지 못하면 목록에 있는 기업도 제외된다.

## 실행

```bash
# 저장한 목록 안에서 자격과 자료를 검증하고, 통과한 기업만 후속 분석한다.
python app.py --candidate-list data/discovery_candidates.json --limit 3

# 후보 탐색·검증 결과만 먼저 확인한다. 투자 평가와 PDF 생성은 실행하지 않는다.
PYTHONPATH=src python -m ai_investment.discover \
  --region 대한민국 --candidate-list data/discovery_candidates.json --limit 3
```

파일은 기업 이름 문자열의 JSON 배열이며 최대 20개다. 파일 순서대로 검증하고
`--limit`은 최종 채택 수의 상한이다. 후보를 억지로 채우지 않는다.
목록 파일을 지정하면 광범위한 기업 탐색과 이름 추출을 생략한다. 검증 중 다른
기업을 자동 추가하지 않는다. 파일을 지정하지 않으면 기존 자동 탐색을 실행하되
아래의 자료 기준을 동일하게 적용한다.

`--company`는 기존의 직접 분석 경로로, 후보 검증을 생략한다.
자료 검증이 필요한 실습에서는 `--candidate-list`를 사용한다. 두 옵션은 함께 쓰지 않는다.

## 후보 채택 기준

1. 요청 도메인·지역·투자 단계에 부합하고 상장·인수 등 완료된 exit가 확인되지 않는다.
2. 제품 설명과 기업별 기술 사양·문서·연구·성능 검증 중 하나 이상을 확인한다.
3. 고객 또는 구체적인 고객군과 실제 도입·운영·판매 근거를 함께 확인한다.
   목표 시장, 고객 로고, 계획, MOU, 투자 발표만으로는 통과시키지 않는다.
4. 검증에 실제 인용된 근거에 서로 다른 출처 그룹이 2개 이상 있어야 한다.
   같은 URL 호스트는 한 그룹, URL 없는 문서는 제목별 한 그룹으로 센다.
   다른 사이트에 재배포된 같은 보도자료까지 독립적으로 검증하는 기준은 아니다.

기업별 검색은 제품·투자, 투자 단계, 기술 자료, 고객 적용의 4개 질의로 제한한다.
검색 자체가 실패하면 오류를 전달하고, 정상 검색의 빈 결과와 구분한다.
정상 검색에서 자료가 부족하면 해당 후보를 제외하고 목록의 다음 기업을 검증한다.
채택·제외 기록은 실행별 `outputs/logs/<trace_id>.jsonl`에 남긴다.

확인한 고객 적용 내용과 인용 ID는 후보 정보에 담는다. 고객 프로필 노드는 해당
내용을 입력으로 받아 분류하며, 출처는 기존 `references`에 연결한다.

이 기준은 후속 분석을 시작할 자료가 있는지 확인하는 사전 검증이다. 모든 관점의
충분성이나 투자 적합성을 보장하지 않는다. 상세 분석의 누락·반대 근거·위험은 기존
Supervisor와 투자 평가에서 그대로 판정한다. 공개 자료가 많은 기업에 치우친 실습
표본이므로 전체 스타트업 시장에 결과를 일반화하지 않는다.
